====================================================
如何修改配置连接到本地 MySQL 数据库
====================================================

一、前置条件
----------------------------------------------------
1. 本地已安装并启动 MySQL 服务（本项目使用 mysql-connector-java 8.0.33，
   兼容 MySQL 5.7 / 8.x 服务端）。
2. 知道自己的 MySQL 账号和密码（例如常用的 root 账号）。

二、第一步：初始化数据库和表
----------------------------------------------------
用任意客户端（Navicat / DBeaver / 命令行）执行项目里的 sql/init.sql，
或命令行执行：

    mysql -u root -p < sql/init.sql

该脚本会：
  - 创建数据库 demo_db
  - 创建表 t_user
  - 插入 3 条测试数据

三、第二步：修改配置文件
----------------------------------------------------
文件路径：
    src/main/resources/application.yml

当前是"虚拟配置"，需要把下面 3 处改成你自己的本地信息：

    spring:
      datasource:
        url: jdbc:mysql://localhost:3306/demo_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
        username: your_mysql_username   <- 改成你的用户名，如 root
        password: your_mysql_password   <- 改成你的密码

说明：
  1. url 中的 localhost:3306
     - localhost 是 MySQL 地址，本机就是 localhost
     - 3306 是端口，如果你本地 MySQL 端口不是 3306，请替换
  2. url 中的 demo_db 是数据库名，要和 init.sql 创建的库名一致；
     如果你想用自己已有的库名，同时修改 url 末尾的库名即可
  3. username / password 改成你本地 MySQL 的真实账号密码

四、第三步：启动并验证
----------------------------------------------------
1. 启动项目（IDEA 中直接运行 DemoSpringbootMysqlApplication，
   或命令行 mvn spring-boot:run）
2. 浏览器或 curl 验证：

    curl http://localhost:8080/api/users

   能返回 init.sql 里插入的 3 条用户数据即表示连接成功。

五、常见连接失败原因
----------------------------------------------------
1. Access denied for user
   -> 用户名或密码错误，检查 username / password
2. Communications link failure / Connection refused
   -> MySQL 服务没启动，或端口不对（先确认 3306 端口是否监听）
3. Unknown database 'demo_db'
   -> 没执行 init.sql 建库，或 url 里库名写错
4. The server time zone value ... is unrecognized
   -> url 中保留 serverTimezone=Asia/Shanghai 参数即可
5. Public Key Retrieval is not allowed
   -> url 中保留 allowPublicKeyRetrieval=true 参数即可
